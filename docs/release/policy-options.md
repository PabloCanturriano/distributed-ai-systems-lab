# Release policy decisions for owner review

Status: the owner accepted the recommendations on 2026-11-26. The selected source license is Apache-2.0; the first release target is `v0.1.0-rc.1`, with GitHub Releases and GHCR for project-owned artifacts. GitHub private vulnerability reporting is enabled for the now-public repository, with the owner responsible for reports. The `release` environment requires owner review and permits `main` only. No registry image publication or prerelease has been executed.

## Selected policy

The release is an evaluation candidate for local use, not a production/security-supported service. Source licensing does not replace dependency licenses. Third-party service images remain pinned upstream references rather than being mirrored to the project registry. For the unmodified, locally pulled Redis server in this evaluation recipe, the prepared policy uses the publisher's AGPLv3 option, with [the exact 8.10.3 source](https://github.com/redis/redis/tree/1a2574ce1551d3de6e0b4a56756c0fdbc6659e4f) and [license terms](https://github.com/redis/redis/blob/1a2574ce1551d3de6e0b4a56756c0fdbc6659e4f/LICENSE.txt) recorded. Its terms remain separate from the Apache-2.0 project source; a modified Redis distribution or hosted service requires a separate review. No unstaffed response deadline is promised.

The registry namespace is `ghcr.io/pablocanturriano/distributed-ai-systems-lab`; each application role has its own image. Published paths must use immutable digests, with Linux AMD64 and ARM64 validation and package/license evidence. Publication remains blocked by unresolved release gates and requires a final review of the exact artifact set.

## License comparison (decision background)

| Candidate       | Permissions and obligations in the published text                                                                                                                                                                          | Decision point                                                                        |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| MIT             | Allows use, modification and redistribution, including commercial use, while retaining its copyright and permission notice. See the [OSI license text](https://opensource.org/license/mit).                                | Prefer a short permission/notice policy when that matches the owner's reuse goals.    |
| Apache-2.0      | Includes an explicit contributor patent grant and termination provision, requires license/notice retention and notices of modified files. See [sections 2–4 of the ASF text](https://www.apache.org/licenses/LICENSE-2.0). | Evaluate explicit patent terms and the additional redistribution/notice requirements. |
| Defer selection | The repository has no selected license. Keep the public release decision pending while deciding the intended audience, ownership and redistribution policy.                                                                | Do not label the project open source or add a license identifier before selection.    |

External reuse is intended under the selected Apache-2.0 terms; contributor ownership is not transferred by this selection. Dependency licenses and notices must also be inventoried for the actual images; choosing a source license does not complete that inventory.
